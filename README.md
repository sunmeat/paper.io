# sunmeat.io

A mobile-first territory-capture arcade game built with React, Vite, and Canvas.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Controls

- Swipe across the arena or use the directional pad on mobile.
- Use the arrow keys or WASD on desktop.
- Leave your territory, draw a loop, and return to claim the enclosed area.
- Your trail is vulnerable while you are outside your territory.

## Current prototype

- Responsive mobile-first interface
- Canvas-based grid arena
- Territory capture and local high score
- Three roaming opponents
- Touch, directional pad, and keyboard controls

This is an original fan-made prototype inspired by the territory-capture genre. It is not affiliated with the creators of Paper.io.
